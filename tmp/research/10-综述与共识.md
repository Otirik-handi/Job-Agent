# 10 LLM Agent 综述与架构共识

日期：2026-08-10
状态：调研完成，供 job-helper 模块对照参考
目的：提炼业界公认的 Agent 组件清单与开放问题，为 job-helper 建"Agent 应包含哪些模块"的权威对照表。

## 调研对象（综述/博客链接 + 一句话）

1. **CoALA: Cognitive Architectures for Language Agents**（2023）https://arxiv.org/abs/2309.02427 —— 认知科学视角，将语言 Agent 统一定义为 memory + action space + decision-making 三件套，并据此回溯整理大量近作。
2. **The Rise and Potential of LLM Based Agents: A Survey**（清华，2023）https://arxiv.org/abs/2309.07864 —— 提出"大脑（LLM）+ 感知 + 行动"三段式架构，覆盖单 Agent、多 Agent、人机协作与 Agent 社会。
3. **A Survey on LLM-based Autonomous Agents**（2024，Lei Wang 等）https://arxiv.org/abs/2308.11432 —— 提出 Profiling / Memory / Planning / Action 四模块架构，含能力获取、评测体系与 6 大挑战。
4. **Agent AI: Surveying the Horizons of Multimodal Interaction**（2024）https://arxiv.org/abs/2401.03568 —— 多模态/具身交互 Agent AI 全景，基础模型作构建块，强调环境接地（embodiment/grounding）。
5. **LLM Powered Autonomous Agents**（Lilian Weng 博客，2023）https://lilianweng.github.io/posts/2023-06-23-agent/ —— 业界流传最广的"三件套"：Planning + Memory + Tool use，LLM 为大脑。

## 各框架的组件划分对比

| 框架 | 规划 | 记忆 | 行动/工具 | 感知 | 反思 | 特色 |
|---|---|---|---|---|---|---|
| CoALA | 决策循环中 propose→evaluate→select | 四类：工作记忆（上下文）/情景/语义/程序 | 内部动作（reasoning/retrieval/learning）+ 外部动作（grounding） | 观察 observation 是循环一环 | 反思属内部 reasoning 动作 | 学习（learning）作为常规决策动作；程序记忆=代码+LLM 权重 |
| 清华 Rise | 大脑（LLM）统一负责 | 大脑能力一部分，未单列框架重点 | 行动模块（含工具调用） | 感知模块（多模态输入） | 未单列 | brain/perception/action 三段式；Agent 社会与涌现 |
| 2024 Survey | 规划模块（无反馈 / 有反馈两派） | 记忆模块：短时=上下文窗口、长时=向量库；统一/混合结构 | 动作模块（目标/生成方式/动作空间/影响四视角） | 感知并入记忆与动作 | 反思属"有反馈规划"（ReAct/Reflexion） | 多了 Profiling 模块（角色刻画：手写/LLM 生成/数据集） |
| Agent AI | 未显式拆分 | 未显式拆分 | 具身行动、多模态交互 | 视觉/语言/环境数据 | — | 虚拟+现实环境的具身 Agent；降低幻觉 |
| Lilian Weng | 任务分解（CoT/ToT）+ 自我反思 | 短时=上下文（ICL），长时=向量库（MIPS/ANN） | 外部 API 工具（MRKL/Toolformer/HuggingGPT） | 工具与环境反馈 | 反思归入规划 | 三件套最简洁的传播版 |

**共识**：规划 / 记忆 / 行动（工具）是三大核心组件；感知与反思或单列、或并入其他模块。**Lilian Weng 三件套与学术框架的对应**：Planning ↔ 规划模块；Memory ↔ 记忆模块（短时=上下文、长时=外部向量存储）；Tool use ↔ 行动模块的外部动作（grounding）。

## 最小 Agent 骨架（共识版控制循环）

```
循环（CoALA 决策循环 / ReAct 推理-行动模式）：
  ① 观察（perceive）：接收用户输入与环境反馈
  ② 工作记忆更新：观察写入上下文（working memory）
  ③ 决策-规划：读长时记忆 + 推理 → 提出并选择候选动作（planning）
  ④ 行动（act）：执行外部工具/动作，产生环境变化（grounding）
  ⑤ 结果回填 → 回到 ①；失败或不确定时可触发反思（reflection）后重试
```

**最小模块集** = 控制循环 + 工作记忆（上下文窗口）+ 长时记忆（外部存储/向量库，可读可写）+ 行动（工具调用）。反思、显式规划、记忆写回（learning）是增强项而非最小项。

## 开放问题与未决问题

1. **评测**：缺统一基准与标准化指标；2024 Survey 单列评测章节（主观+客观）；清华点名 agent evaluation。
2. **长时记忆**：如何学习/写回（learning 作常规动作）、压缩与遗忘、内部/外部资源边界（CoALA 明确列为 open question）。
3. **多 Agent 协调**：通信协议、角色分工、群智涌现（清华 Agent society；2024 多 Agent 协作）。
4. **安全与对齐**：幻觉与环境错误输出（Agent AI）、知识边界、prompt 鲁棒性、角色扮演能力（2024 的 6 大挑战）；校准、可解释性、部署扩展（清华）。
5. **人机协作**：确认机制与人类反馈（human-in-the-loop）仍是研究重心，未有统一方案。

## job-helper 模块对照表（以共识框架为纲）

| 共识模块 | 现状 | 对照评价 |
|---|---|---|
| 行动/工具 | 已有：11 个领域工具 + tool-factory（`src/agent/tools/`、`src/agent/tool-factory.ts`） | 骨架中最强的一环；两段式确认（applyJob/tailoredResume）即 human-in-the-loop |
| 工作记忆 | 已有：多会话 + 每会话最近约 20 轮消息（`src/agent/agent.ts` 上下文组装） | 纯滑动窗口，无压缩/摘要，长对话会截断 |
| 感知 | 已有：文本/文件导入（docx/txt/md）；部分：MCP 浏览器抓取岗位 URL 在设计中 | PDF 按设计拒绝（反扫） |
| 长时记忆 | 缺失：SQLite 只存领域实体（简历/岗位/投递），**无 Agent 可检索的经验/语义记忆层** | CoALA 的 episodic/semantic 记忆缺位 |
| 显式规划 | 缺失（P1）：规划隐含在 system prompt 里，无 plan 表示与步骤跟踪 | 2024 Survey 规划模块的"无反馈规划"也未落地 |
| 反思/自检 | 部分：llm-call 有 schema repair（≤2 次），但无 LLM 自我反思/迭代环 | Reflexion 式反思未做 |
| 能力获取（程序记忆） | 部分：skill 系统调研已完成（`docs/designs/2026-08-10-skill-system-research.md`），尚未实现 | 对应 CoALA procedural memory / 能力运行时加载 |
| Profiling | 部分：静态 system prompt 定角色（求职助手），无动态用户画像模块 | 单用户本地场景，静态 profile 够用 |
| 评测 | 缺失（P2）：无 Agent 级评测基线，仅核心纯逻辑单测 | 符合工程原则但缺行为回归 |
| 多 Agent | 明确不做（设计边界 6.3） | 单用户场景合理 |

**优先级建议**：P0=长时记忆（经验/语义层）、反思环；P1=显式规划、skill 系统落地；P2=Profiling、评测基线。多 Agent 维持不做。
