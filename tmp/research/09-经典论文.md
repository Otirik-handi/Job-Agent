# 09 LLM Agent 经典论文精选

> 为 job-helper 建立的论文级知识底座。每篇仅一句核心机制 + 一句对求职 Agent 的启发，供快速检索与对齐设计。信息均来自 arxiv 官方摘要页，日期 2026-08-10。

## 论文清单（标题/年份/会议 | 核心机制一句话 | 对求职 Agent 的启发一句话）

1. **ReAct（Yao et al., 2023 / ICLR 2023）**
   核心机制：让 LLM 交替生成"思考轨迹（Thought）+ 动作（Action）+ 观察（Observation）"，在决策中边推理边调用外部信息源，降低幻觉与错误传播。
   对求职 Agent：当前所有 Agent 的"agent loop"范式的源头——求职对话里"先想再查再答"（检索岗位库/面试经验库 + 推理）就是这个循环的具体化。

2. **Reflexion（Shinn et al., 2023 / NeurIPS 2023）**
   核心机制：不做梯度更新，而是把失败的反馈信号转成自然语言的"反思文本"存进情景记忆，供下一次尝试指导决策（HumanEval 91% pass@1）。
   对求职 Agent：每次模拟面试/简历反馈后的"反思记忆"可直接复用——失败原因写进记忆，下一轮改掉，是零成本持续变强的最简方案。

3. **Tree of Thoughts（Yao et al., 2023 / NeurIPS 2023）**
   核心机制：把单条思维链扩展成思维树，对每个中间思路做"评估/展望/回溯"，用搜索代替从左到右贪心解码（Game of 24：CoT 4% → ToT 74%）。
   对求职 Agent：复杂决策（如"该投哪类公司/如何权衡 offer"）先枚举多个候选路径再评估，避免一条路走到黑的贪心决策。

4. **Plan-and-Solve（Wang et al., 2023 / ACL 2023）**
   核心机制：零样本下先让模型"制定分步计划再执行"，修复 Zero-shot-CoT 的漏步与计算错误（PS+ 进一步细化指令）。
   对求职 Agent：面试模拟/职业规划类回答前先输出计划框架（"先问需求→拆目标→分步给方案"），回答质量与可解释性双升。

5. **Toolformer（Schick et al., 2023 / arXiv, NeurIPS 2023）**
   核心机制：自监督学习让模型自己决定"何时调用 API、传什么参数、如何利用返回结果"，微调即可学会用工具，不牺牲语言建模能力。
   对求职 Agent：证明工具调用能力可以靠自监督沉淀——把"查岗位→读 JD→生成简历片段"这类稳定调用链固化进模型，比每次都提示更稳。

6. **Generative Agents（Park et al., 2023 / UIST 2023, Smallville）**
   核心机制：记忆流（memory stream）+ 定期反思（reflection）+ 按相关性/时效动态检索，让 Agent 表现出可信的人类行为（25 个 Agent 自主组织派对）。
   对求职 Agent：求职者画像/沟通历史的"记忆流"就是它的直接应用——记住用户偏好、按时效与相关度召回，做个性化陪伴而非每次冷启动。

7. **Voyager（Wang et al., 2023 / arXiv）**
   核心机制：Minecraft 中"自动课程 + 可成长的技能库（可执行代码）+ 迭代提示（环境反馈/报错/自验证）"，黑盒调用 GPT-4，终身学习无需微调。
   对求职 Agent：技能库思想最值钱——把"写自我介绍/STAR 拆解/谈薪话术"沉淀为可复用技能模块，越用越多，Agent 能力随积累成长。

8. **MemGPT（Packer et al., 2023 / arXiv，后演化为 Letta）**
   核心机制：借鉴操作系统内存分层，把 LLM 上下文当"主存"、外部存储当"磁盘"，用函数调用做换入换出 + 中断控制，突破上下文窗口。
   对求职 Agent：长对话（长期求职跟踪、多轮面试复盘）必须做分层记忆，不能硬塞上下文——这是对话型 Agent 的工程刚需。

9. **CoALA（Sumers et al., 2023 / TMLR）**
   核心机制：用"模块化记忆（工作/情景/语义）+ 结构化动作空间（内部记忆操作/外部环境动作）+ 决策过程（规划/执行/学习）"统一描述一切语言 Agent。
   对求职 Agent：写代码前的设计图——先按 CoALA 画好记忆分层与动作清单，再动手，避免每个功能各搞一套临时架构。

10. **The Rise and Potential of LLM-based Agents（Xi et al., 2023 / THU 综述）**
    核心机制：提出"大脑（LLM）+ 感知 + 行动"三件套框架，系统性梳理单 Agent、多 Agent、人机协作与 Agent 社会行为。
    对求职 Agent：用它当"设计体检表"自查：感知层（接收什么输入）、大脑层（推理/规划）、行动层（输出什么动作）是否齐全。

11. **AI Agents That Matter（Kapoor et al., 2024 / arXiv）**
    核心机制：批判 Agent 评测只盯准确率，主张成本-准确率联合优化、严格划分测试集、标准化评测，防止过拟合与虚假 SOTA。
    对求职 Agent：选型与做评测时务必算"真实成本/延迟/失败率"——别为了一个演示亮点牺牲每次对话的成本与稳定性。

12. **SWE-agent（Yang et al., 2024 / NeurIPS 2024）**
    核心机制：提出 Agent-Computer Interface（ACI）——为 Agent 专门设计文件查看/编辑/测试接口，而非迁就人类界面，SWE-bench 12.5% pass@1。
    对求职 Agent：接口即能力——求职 Agent 的工具接口（检索语法、输出格式）要按 LLM 的偏好设计，而不是照搬人类 UI。

13. **A Survey on LLM-based Autonomous Agents（Wang et al., 2023 / Frontiers of Computer Science）**
    核心机制：给出"构建（profile/记忆/规划/动作）+ 应用（社科/自然/工程）+ 评测"的统一研究框架，是入门全景图。
    对求职 Agent：其中的 profile/记忆/规划/动作四件套，可作为求职 Agent 模块划分的最简脚手架。

14. **Tool Learning（Qin et al., 2023 / arXiv）与 LLM Multi-Agent Systems 综述（Guo et al., 2024 / arXiv）**
    核心机制：前者系统化"任务分解→工具选择→推理调用"的工具学习框架；后者梳理多 Agent 的画像、通信与协作机制。
    对求职 Agent：工具学习提醒"选对工具比堆参数重要"；多 Agent 部分启发未来可做"求职顾问 + HR 模拟官 + 简历评审"角色分工。

## 论文共识（沉淀出的 Agent 设计共识清单）

- **推理与行动一体（Reasoning-Acting）**：ReAct 确立 Thought/Action/Observation 循环，几乎成为一切 Agent 引擎的默认执行范式。
- **记忆必须分层**：Generative Agents（情景/语义）、MemGPT（主存/外存）、CoALA（工作/情景/语义三块）共同指向"短期工作记忆 + 长期存储 + 检索"的标准配置。
- **自省与反思闭环**：Reflexion 证明用自然语言反思（而非权重更新）就能显著提升，是"廉价可迭代"的自我学习通道；Voyager 的环境反馈+自验证同理。
- **工具/接口学习是能力上限**：Toolformer（自监督学调用）、SWE-agent（为 Agent 设计接口）说明"外部能力"决定 Agent 的能力边界，且接口要为 LLM 优化。
- **规划先行、搜索兜底**：Plan-and-Solve 主张先计划后执行；ToT 在计划之上加评估与回溯，用于高风险/高代价决策。
- **架构分层与框架化**：CoALA、THU 综述、"brain+perception+action"等把 Agent 收敛为"记忆-动作-决策"的模块化框架，避免临时拼装。
- **评测要诚实**：AI Agents That Matter 提醒：只看准确率会过拟合，成本、鲁棒性、可复现性必须同场竞技。

## 对 job-helper 启发最大的 Top 5 论文及理由

1. **ReAct**：最直接的工程范式——求职 Agent 的每次回复（检索岗位库/简历库 + 推理 + 组织回答）就是它的循环；先照抄这个循环，再谈优化。
2. **MemGPT（Letta）**：求职是多轮、跨周的长对话（目标、进度、面试复盘），分层记忆是"记得住用户"的刚需，架构上直接可用。
3. **Generative Agents**：记忆流+反思+检索 = 求职者数字分身——把用户画像与交互历史做成可检索记忆，是"个性化"而非"千人一面"的分水岭。
4. **Reflexion**：对"模拟面试/简历修改"这类可回放场景，反思式自我改进成本最低、见效最快，天然契合求职训练闭环。
5. **SWE-agent（或 AI Agents That Matter）**：SWE-agent 提醒工具接口要为 LLM 设计（检索与输出格式）；AI Agents That Matter 提醒上线前先算真实成本与失败率——两者是"能跑"到"好用"的护栏。

## 论文→工程的映射（哪些已进主流框架）

- **ReAct → LangChain / OpenAI Function Calling / 各类 Agent SDK** 的默认 AgentExecutor 循环（thought→tool→observation）。
- **MemGPT → Letta（原 MemGPT 项目）**：正式产品化为带自我编辑记忆的分层记忆服务器；也催生各家长记忆/记忆压缩方案。
- **Generative Agents → LangChain Memory、Mem0、Zep 等记忆系统**：memory stream + 反思检索成为记忆类库的默认参考实现。
- **Reflexion → LangGraph / Agent 编排框架内置反思节点**，以及各类 Self-Critique / 批评家模式。
- **Plan-and-Solve / ToT → 各类"规划器（Planner）+ 执行器（Executor）"框架**与 LangGraph 的 Plan-and-Execute 模式。
- **Toolformer → 工具/函数调用微调**（Gorilla、模型原生 function calling 训练）的路线鼻祖。
- **CoALA / 各综述 → 架构设计语言**：设计文档里用 memory/action/decision 表述，已成为业界默认词汇。
