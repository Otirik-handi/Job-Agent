# 求职站点真实可抓取性评估报告（Boss直聘 / 猎聘 / 智联 / 前程无忧）

日期：2026-08-12
状态：实测完成，供 web 工具设计引用（承接 `2026-08-12-web-tools-research.md` §7.4 问题 1）
修正：2026-08-12 补充 OpenCLI 路线实测后，Boss直聘结论由"不可自动抓取"修正为"需登录态可采集"，详见 `2026-08-12-opencli-collection-assessment.md`
关联文档：`2026-08-12-web-tools-research.md`（Web 工具调研报告）、`2026-08-10-agent-roadmap-discussion.md`（P2 批次 D 定稿）
评估环境：本机（win32），直连 + 本地代理均可出网；浏览器评估使用 ZCode 内嵌浏览器（真实 Chromium 内核，1280×720）

## 1. 评估目标与方法

调研报告 §7.4 问题 1：求职站点（Boss直聘/猎聘/智联/前程无忧）的可抓取性现实评估——哪些能 fetch、哪些必须登录、反爬强度——决定 web-fetch 的真实覆盖面和预批准域名列表内容。

评估分两层，对应未来工具的两种实现路线：

- **curl 层**：模拟自建 web-fetch（HTTP 直抓 + 解析），使用浏览器 UA、跟随重定向，检查状态码、最终 URL、页面体积、内容形态（SSR 直出 vs JS 壳 vs 反爬页）、编码。
- **浏览器层**：模拟 web-browse / Jina Reader（带浏览器引擎的渲染抓取），检查 JS 渲染后内容可见性、登录墙、验证码强度。验证码只做识别不做绕过（绕过验证码超出工具能力边界，也超出评估目的）。

## 2. 逐站结果

### 2.1 Boss直聘（zhipin.com）—— 不可自动抓取 ❌

| 项目 | 实测结果 |
|---|---|
| 首页 curl | **302 → `/web/passport/zp/verify.html`（安全验证页）**，1 次重定向即被拦 |
| 验证页特征 | 页面含 `captcha` / `slider` 字样，43KB；文案"当前 IP 地址可能存在异常访问行为，完成验证后即可正常使用" |
| 浏览器访问 | 同样被拦到验证页；点击"点击按钮进行验证"后**升级为图形点选验证码**（"请选中下图中所有的：" + 确认/刷新按钮） |
| 验证码类型 | 点击验证 → 图形点选（需图像识别 + 模拟点击），**无法自动通过** |
| robots.txt | 禁爬极严：`/job_detail/l*.html`（职位详情）、`/web/geek/*`、`/web/boss/*`、所有带 query 参数（`/*?*`）全部 Disallow |
| 登录墙 | 内容页（搜索/详情）需登录 + 验证 |

**结论**：本环境 IP 被 Boss 风控标记，纯 HTTP 与浏览器自动化（含真实 Chrome 扩展）均不可行——OpenCLI 实测未登录时报"您的IP地址存在异常行为 (code=35)"。**修正：登录态下（opencli boss login，手机号+验证码）可完整采集列表与详情**，详见 `2026-08-12-opencli-collection-assessment.md`。未登录场景下 web-fetch / web-browse 对 Boss直聘仍按"预期失败"处理（如实返回失败，提示用户走登录态采集或手动查看）。

### 2.2 猎聘（liepin.com）—— 详情页可直抓；列表页需渲染 ⚠️

| 项目 | 实测结果 |
|---|---|
| 首页 curl | 200，无重定向 |
| 搜索页 curl（/zhaopin/） | 200，34KB，**JS 壳**：HTML 无职位卡片、无职位链接（仅导航/静态链接），职位数据靠前端 XHR 加载 |
| 搜索页浏览器 | **渲染后职位列表完整可见**（职位名/薪资/经验/学历 + 详情链接），无登录墙 |
| 详情页 curl（/job/1984638207.shtml） | **200，182KB，职位内容可直抓**；详情链接格式 `https://www.liepin.com/job/<id>.shtml` |
| 详情页浏览器 | 完整职位介绍可见（岗位职责/任职要求全文），**无需登录**（仅"投简历"动作需登录） |
| 编码 | **GBK 编码**（title 字节显示乱码），web-fetch 需做 GBK→UTF-8 转换 |
| robots.txt | `/zhaopin/` 列表路径未禁；`/user/`、`/*?*`（带参数 URL）禁 |

**结论**：详情页 = 自建 web-fetch 可直接覆盖（+GBK 转码）；列表页 = curl 拿不到，需浏览器渲染（Jina Reader / 未来 web-browse）。

### 2.3 智联招聘（zhaopin.com）—— 全链路可直抓 ✅

| 项目 | 实测结果 |
|---|---|
| 首页 curl | 200 |
| 搜索页 curl | `sou.zhaopin.com/?jl=530&kw=前端` → 302 到 `www.zhaopin.com/sou/jl530/kwA96NLRO`，**351KB SSR 直出**：含 27 处命中关键词、完整职位卡片 + 详情链接（`http://www.zhaopin.com/jobdetail/CC<公司ID>J<职位ID>.htm`） |
| 详情页 curl | **200，1.78MB SSR 直出**：title 为真实职位名（"前端开发工程师-sd招聘_浪潮集团招聘 - 智联招聘"），含职位描述/职责等完整内容 |
| 反爬特征 | 无显式 WAF/验证码痕迹 |
| robots.txt | `/user/*`、`/api/*`、`/*?*` 禁；**`/jobdetail/*.htm` 未禁**（详情页合规可抓） |

**结论**：唯一 curl 全链路可直抓的站点，且详情页 robots 允许。**自建 web-fetch 的首选覆盖目标**。

### 2.4 前程无忧（51job.com）—— curl 被 WAF 拦截；浏览器可过 ⚠️

| 项目 | 实测结果 |
|---|---|
| 首页 curl | 200 |
| 搜索页 curl（we.51job.com/pc/search） | 200，7.9KB **JS 壳**（`id="app"`），壳内加载阿里系反爬组件（`g.alicdn.com/.../antidom.js`），无内嵌职位数据 |
| 搜索页浏览器 | 渲染后可见职位列表（推荐位 + 真实链接 `https://jobs.51job.com/<城市>/<id>.html`）；注意：搜索"前端"显示"暂无相关职位"且城市定位到娄底（IP 定位偏差/搜索未真正执行），推荐位内容可见 |
| 详情页 curl（jobs.51job.com/loudi/173005233.html） | 200 但 **95KB 全是阿里云 WAF JS 挑战页**：`aliyun_waf_aa` meta + 混淆脚本（`var _0x2576...`）+ `renderData` 加密 textarea，无任何职位内容 |
| 详情页浏览器 | **WAF 放行，完整职位页可见**：真实 title（"测试主管G04194招聘 | 娄底 | 9千-1.5万 | 华达汽车空调（湖南）有限公司 | 前程无忧"）、岗位职责/任职要求全文，**无需登录** |
| robots.txt | 302 → `/in/missing.php`（robots.txt 不可用） |

**结论**：自建 curl fetch 完全不可行（WAF JS 挑战需执行混淆脚本计算 cookie）；**带浏览器引擎的抓取（Jina Reader / 未来 web-browse）可过 WAF**，详情页内容完整、无需登录。

## 3. 汇总对比

| 站点 | curl 列表 | curl 详情 | 浏览器列表 | 浏览器详情 | 登录墙 | 反爬类型 | robots 详情页 |
|---|---|---|---|---|---|---|---|
| Boss直聘 | ❌ 验证页 | ❌ 验证页 | ❌ 图形点选验证码（未登录） | ✅ 登录态可采集（OpenCLI） | 需登录 | IP 风控 + 图形验证码（未登录） | 禁 |
| 猎聘 | ❌ JS 壳 | ✅ 可抓（GBK） | ✅ 可见 | ✅ 可见 | 仅投递需登录 | 无显式（JS 渲染屏障） | 未禁 |
| 智联 | ✅ SSR 直出 | ✅ SSR 直出 | ✅（SSR） | ✅（SSR） | 无 | 无显式 | 未禁 |
| 前程无忧 | ❌ JS 壳 | ❌ 阿里云 WAF | ✅ 可见 | ✅ 可见（WAF 放行） | 无 | 阿里云 WAF JS 挑战 | 不可用 |

可抓取性评级：**智联 > 猎聘（详情） > 51job（需渲染） > Boss（不可自动抓）**。

## 4. 对 web 工具设计的启示

1. **web-fetch（自建 curl 路线）覆盖矩阵**：智联搜索页+详情页（SSR 直出）、猎聘详情页（需 GBK→UTF-8 转码）可直接覆盖；51job / 猎聘列表页 / Boss 全部失败。
2. **Jina Reader 降级的必要性**：51job（WAF 需执行 JS）与猎聘列表页（XHR 渲染）必须走带浏览器引擎的抓取——这正是调研报告"自建为主 + Jina Reader 免费 API 降级"组合的实测依据；预计 Jina 对这两站可用（浏览器渲染 + 服务端 IP，待接入时验证）。
3. **web-browse（Playwright）后置判断成立**：猎聘/51job 的浏览器渲染抓取仅需"打开+等待渲染+取 DOM"，不需要交互；Boss 即使上 Playwright 也过不了图形验证码。**首批无需 web-browse 的真实结论**（而非仅凭成本推断）。
4. **预批准域名列表**：建议预批准 `zhaopin.com`、`liepin.com`、`51job.com`（含子域 `sou.zhaopin.com`、`we.51job.com`、`jobs.51job.com`）；`zhipin.com` 保留但预期失败。robots 合规：智联/猎聘详情页路径均未禁，可抓；带参数 URL 均被禁（遵守则列表页只能走渲染抓取，与实测一致）。
5. **Boss直聘处理策略**：未登录态 web 工具如实返回"需登录+验证"；登录态下可走 OpenCLI 采集（见 `2026-08-12-opencli-collection-assessment.md`）；人工查看后粘贴/导入路径（import-job-opportunity）继续作为兜底。
6. **编码处理**：猎聘详情页 GBK，web-fetch 的 HTML→Markdown 管线必须包含字符集检测与转码（header 或 meta 声明优先，ICU/chardet 类库兜底）。

## 5. 限制与后续待测

- 本评估基于本机 IP（已被 Boss 风控标记），真实家庭/办公网络下各站反爬强度可能不同——**Boss 在正常网络下的表现待用户实网复测**；51job 搜索"暂无相关职位"疑为 IP 定位异常，正常网络下搜索功能应可用。
- 未测站点：拉勾（lagou.com，已并入脉脉生态）、脉脉招聘、公司官网 careers 页（如大厂招聘官网多为 SSR/静态，预计可抓）、垂直渠道（牛客/实习僧等）。company-research 主要依赖公司官网 + 新闻，与招聘平台无关，可在批次 D 中一并实测。
- 未测动作：51job/猎聘的"登录后可见"字段（完整联系方式等）——web-fetch 明确不做登录态抓取，人工导入路径承接。
- Jina Reader 对 51job/猎聘的实测放批次 D 实现时验证（本评估仅证明"浏览器渲染可行"，Jina 服务端 IP 与本地 IP 风控状态不同）。

## 6. 一句话总结

实测四站：**智联全链路可 curl 直抓（首选）**，猎聘详情页可直抓（GBK 转码即可）、列表页需渲染，51job 被阿里云 WAF 拦截但浏览器渲染可过、无需登录，**Boss直聘本环境被 IP 风控 + 图形验证码 + 登录墙三重拦截，不可自动抓取**——印证调研报告"自建 fetch + Jina 降级、web-browse 后置"的组合判断，并给出预批准域名列表与 Boss 人工导入兜底的具体设计输入。
