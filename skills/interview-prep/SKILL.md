# 面试准备

## 1. 适用场景与边界

- 适用：面试前准备（常见问题演练、自我介绍打磨）、模拟面试问答、面试复盘
- 边界：**回答内容只基于简历真实经历**，不帮用户编造面试故事；对行为面试问题给的是组织方法而非标准答案
- 产出：按需给出——自我介绍稿、分类问题清单与回答要点、STAR 演练框架、向面试官提问清单

## 2. STAR 框架

回答行为类问题（"讲一次你……的经历"）统一用四步组织：

- **S（情境）**：一句话交代背景（什么项目/什么场景、时间与规模），不长篇铺垫
- **T（任务）**：说清你的任务或责任边界（注意是"你"的职责，不是团队的整体职责）
- **A（行动）**：重点段落——你具体做了什么、怎么决策、遇到什么阻碍怎么处理；用第一人称"我"，突出个人动作
- **R（结果）**：用数字或明确事实收尾；无数字时给结果事实（上线/交付/获得认可）

组织要点：

- 时长控制在 1.5-3 分钟/题；S+T 不超过 1 分钟，A 占一半以上
- 每个经历可预演 2 个角度：成功案例（体现能力）与挫折案例（体现复盘与抗压）
- 演练时先写要点再口头复述，不背诵全文
- **每个素材按三个时长版本准备**：完整版 2 分钟（"讲一次你…"主问题用）、短版 60 秒（追问用）、一句话版 15 秒（"举个例子"用）——先把 S/T/A/R 完整展开，再压缩时保留 A 的动作链与 R 的数字，S/T 一句带过

## 3. 常见问题分类（含示例）

### 3.1 自我介绍（必考题）

- 结构：当前状态（1 句）→ 与岗位最相关的 2-3 段经历（各 1-2 句，带数字）→ 为什么投这个岗位（1 句）
- 时长 1-2 分钟；内容与简历一致，不新增简历外的事实
- 示例问法："先做个自我介绍吧。"

### 3.2 项目经历（深挖题）

- 示例问法："讲讲你最有成就感的项目""这个项目的技术难点是什么""项目里你具体负责哪部分""如果重做一次，哪里会改进"
- 准备方法：为简历中每个重点项目准备 STAR 版讲述 + 难点 + 个人贡献边界 + 复盘；技术岗附架构图或数据结构口头描述

### 3.3 行为面试（能力考察）

- 示例问法："讲一次你解决冲突的经历""有没有遇到 deadline 冲突的时候""讲一次你主动推动事情改进的经历""你被批评最狠的一次"
- 准备方法：从简历经历中选 3-5 个可复用素材（冲突/压力/推动/失败），按 STAR 预演，同一个素材能应对多道题
- **按 5 类能力清点素材覆盖度**（避免"几个素材应对所有题"的盲区）：
  - 领导力：带队过挑战 / 处理冲突 / 做艰难决定 / 授权 / 培养他人
  - 问题解决：解决复杂问题 / 修复坏流程 / 应对意外阻碍 / 信息不全时决策 / 主动改进
  - 协作：与难搞的同事合作 / 对齐跨职能干系人 / 建立共识 / 跨团队协作 / 无授权影响他人
  - 成就：超额达标 / 压力下交付 / 超出职责 / 主动进取 / 最自豪的成就
  - 失败与成长：犯错并学习 / 收到批评性反馈 / 失败后恢复 / 基于学习改变方法
  - 清点结果明确标注：已有素材的类别与缺素材的类别（缺的类别提示用户补充真实经历，不编造）

### 3.4 技术考察（岗位相关）

- 示例问法：基础概念题（"XX 的原理是什么"）、场景设计题（"如果让你设计 XX 你会怎么做"）、手写/口述代码题
- 准备方法：对照 JD 关键词（见 jd-analysis）逐项过一遍；不会的题诚实说"这部分了解不深"，并给出已知的相邻知识，不硬编

### 3.5 敏感题（离职动机/缺点/失败/薪资）

- **离职动机**："为什么离开上一家公司""为什么有这段空窗期"——**只说事实，不攻击前雇主**；用"追求/选择"句式代替"不满"句式（如"希望做更偏 X 方向的工作"）；若理由敏感（被裁、与领导不合），指导如何转为中性表达（"业务调整""个人发展方向变化"），不教撒谎
- **缺点（weakness 公式）**："你最大的缺点是什么"——按**真实缺点 + 自我认知 + 改进步骤**三段回答：缺点必须真实（不是"我太追求完美"式话术），认知表明你清楚代价，改进步骤具体可执行（如"我容易过度关注细节拖慢进度——我意识到后会给任务设时间上限、主动寻求'够好就行'的反馈，并在合适场景委派细节工作"）
- **失败经历（三要素）**："讲一次你失败的经历"——**真实失败（非谦虚式炫耀）+ 学到了什么 + 如何应用**；用具体的失败案例（如某项目判断失误），说明后续如何改变做法
- **薪资问题（deflection）**：面试中被问期望薪资——先反问预算区间（"我对薪酬比较灵活，更关注岗位是否合适，方便告知预算区间吗？"）；被逼问时给区间（"基于我的调研和经验，我在看 X–Y，愿意讨论完整薪酬构成"）——与 negotiation skill 的场景话术同一套（refine-08/09 同源），不透露当前薪资，重定向到市场价与目标区间

### 3.6 反向问题（求职者提问）

- 必问清单（挑 2-3 个）：
  - 这个岗位最重要的一项 KPI/产出是什么
  - 团队目前最大的挑战是什么
  - 入职后前 3 个月对新人期待是什么
  - 团队氛围与协作方式（远程/onsite、汇报关系）
  - 该岗位的成长路径（晋级、转岗可能）
- 不问：薪酬细节（放 offer 阶段）、网上可查的信息（公司规模）
- **按面试对象分组**（国内多轮面试：HR/技术/交叉/高管面）：
  - 面试官（直属/技术面）：岗位 30/60/90 天成功标准、团队最大挑战、绩效怎么衡量、团队结构
  - 团队成员（交叉面）：典型的一天/一周、在这里工作最享受什么、团队怎么协作、希望新人提前知道什么
  - 高管（终面）：公司未来一年战略重点、团队如何贡献公司目标、什么让你对公司保持兴奋

## 4. 回答组织方法（通用）

- **先结论后展开**：第一句直接回答问题核心，再给细节；避免绕圈子
- **每答必带证据**：结论后跟一条简历中的真实经历/数字支撑
- **不会就诚实**：不编造、不背范文；表示"我了解不深，但我知道……"，体现学习能力
- **时间感**：长答控制在 3 分钟内，观察面试官反应适时收尾

## 5. 输出格式

按用户要求给对应产物：

1. **自我介绍稿**：1-2 分钟版 + 30 秒极简版（每句标注简历出处）
2. **问题清单与回答要点**：按第 3 节分类列出，每题给"回答要点 + STAR 素材建议 + 注意事项"；结合具体岗位时优先命中 JD 要求
3. **STAR 演练表**：用户选定的经历 → 四列填写 S/T/A/R 要点，并给三个时长版本（2 分钟完整版 / 60 秒短版 / 15 秒一句话版）
4. **能力覆盖清单**：按 5 类能力（领导力/问题解决/协作/成就/失败成长）逐项标注"已有素材/缺素材"（见 §3.3）
5. **提问清单**：按面试对象分组（面试官/团队成员/高管）给出 3-6 个问题
6. **红线答案提示**：基于岗位与简历给出别提的话题、别批评的前雇主方面、警惕的陷阱题
7. **模拟面试**：按用户要求逐题提问并点评（点评聚焦组织方法与真实性，不点评内容对错）
