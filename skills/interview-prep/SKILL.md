# 面试准备

## 1. 适用场景与边界

- 适用：面试前准备（常见问题演练、自我介绍打磨）、模拟面试问答、面试复盘
- 边界：**回答内容只基于简历真实经历**，不帮用户编造面试故事；对行为面试问题给的是组织方法而非标准答案
- 产出：按需给出——自我介绍稿、分类问题清单与回答要点、STAR 演练框架、向面试官提问清单

## 2. STAR 框架

回答行为类问题（"讲一次你……的经历"）统一用四步组织：

- **S（情境）**：一句话交代背景（什么项目/什么场景、时间与规模），不长篇铺垫
- **T（任务）**：说清你的任务或责任边界（注意是"你"的职责，不是团队的整体职责）
- **A（行动）**：重点段落——你具体做了什么、怎么决策、遇到什么阻碍怎么处理；用第一人称"我"，突出个人动作
- **R（结果）**：用数字或明确事实收尾；无数字时给结果事实（上线/交付/获得认可）

组织要点：

- 时长控制在 1.5-3 分钟/题；S+T 不超过 1 分钟，A 占一半以上
- 每个经历可预演 2 个角度：成功案例（体现能力）与挫折案例（体现复盘与抗压）
- 演练时先写要点再口头复述，不背诵全文

## 3. 常见问题分类（含示例）

### 3.1 自我介绍（必考题）

- 结构：当前状态（1 句）→ 与岗位最相关的 2-3 段经历（各 1-2 句，带数字）→ 为什么投这个岗位（1 句）
- 时长 1-2 分钟；内容与简历一致，不新增简历外的事实
- 示例问法："先做个自我介绍吧。"

### 3.2 项目经历（深挖题）

- 示例问法："讲讲你最有成就感的项目""这个项目的技术难点是什么""项目里你具体负责哪部分""如果重做一次，哪里会改进"
- 准备方法：为简历中每个重点项目准备 STAR 版讲述 + 难点 + 个人贡献边界 + 复盘；技术岗附架构图或数据结构口头描述

### 3.3 行为面试（能力考察）

- 示例问法："讲一次你解决冲突的经历""有没有遇到 deadline 冲突的时候""讲一次你主动推动事情改进的经历""你被批评最狠的一次"
- 准备方法：从简历经历中选 3-5 个可复用素材（冲突/压力/推动/失败），按 STAR 预演，同一个素材能应对多道题

### 3.4 技术考察（岗位相关）

- 示例问法：基础概念题（"XX 的原理是什么"）、场景设计题（"如果让你设计 XX 你会怎么做"）、手写/口述代码题
- 准备方法：对照 JD 关键词（见 jd-analysis）逐项过一遍；不会的题诚实说"这部分了解不深"，并给出已知的相邻知识，不硬编

### 3.5 离职动机（敏感题）

- 示例问法："为什么离开上一家公司""为什么有这段空窗期"
- 回答原则：**只说事实，不攻击前雇主**；用"追求/选择"句式代替"不满"句式（如"希望做更偏 X 方向的工作"）
- 若理由敏感（被裁、与领导不合），指导如何转为中性表达（"业务调整""个人发展方向变化"），不教撒谎

### 3.6 反向问题（求职者提问）

- 必问清单（挑 2-3 个）：
  - 这个岗位最重要的一项 KPI/产出是什么
  - 团队目前最大的挑战是什么
  - 入职后前 3 个月对新人期待是什么
  - 团队氛围与协作方式（远程/onsite、汇报关系）
  - 该岗位的成长路径（晋级、转岗可能）
- 不问：薪酬细节（放 offer 阶段）、网上可查的信息（公司规模）

## 4. 回答组织方法（通用）

- **先结论后展开**：第一句直接回答问题核心，再给细节；避免绕圈子
- **每答必带证据**：结论后跟一条简历中的真实经历/数字支撑
- **不会就诚实**：不编造、不背范文；表示"我了解不深，但我知道……"，体现学习能力
- **时间感**：长答控制在 3 分钟内，观察面试官反应适时收尾

## 5. 输出格式

按用户要求给对应产物：

1. **自我介绍稿**：1-2 分钟版 + 30 秒极简版（每句标注简历出处）
2. **问题清单与回答要点**：按第 3 节分类列出，每题给"回答要点 + STAR 素材建议 + 注意事项"；结合具体岗位时优先命中 JD 要求
3. **STAR 演练表**：用户选定的经历 → 四列填写 S/T/A/R 要点
4. **提问清单**：按"必问/可选"给出 3-6 个问题
5. **模拟面试**：按用户要求逐题提问并点评（点评聚焦组织方法与真实性，不点评内容对错）
