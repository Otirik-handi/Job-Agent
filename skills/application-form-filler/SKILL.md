# 申请表填写

## 1. 核心原则

- 表单答案**直接且具体**——不是塞进文本框的求职信。每个字段都有其目的，回答清楚目的就停。
- 答案要"像一个真人打的字，不像模板填充"；所有内容基于简历真实经历与 JD 上下文，**不虚构年限、项目、技能**。

## 2. 写前必读三样（缺料先要）

1. **岗位描述（JD）**——镜像它的语言与优先级（但不复述回去）
2. **候选人的简历/档案**——抽取真实项目、角色与指标
3. **具体问题本身**——精确回答被问的，不是你想被问的

- 用户没提供 CV 或 JD 时**先要**（"用哪份简历？针对哪个岗位？"），不凭空生成（意图澄清协议，见对话层规则）。

## 3. 题型分类处理（7 类）

### Type 1 经验/背景题（"你有几年 X 经验"）

- 格式：`[技术/技能] — [X 年]。一句话说明用它做过什么（带具体项目）。`
- 规则：最常用技能打头；**年限诚实不注水**；每个声明锚定真实项目；间接经验明说并转到相关经验

### Type 2 为什么这家公司（"为什么想加入我们"）

- 格式：`[对公司的具体兴趣点——不泛泛] + [怎么连接你的真实工作]`
- 规则：必须公司特定、无套话；必要时先调研（company-research）；**150 字内**；**不要把 JD 复述回去**

### Type 3 作品集/工作样例

- 格式：项目列表，一行描述，最相关打头
- 规则：只放岗位相关的；有可验证链接/成果就放；不为显高产注水

### Type 4 技术技能/评分题（"请勾选你的熟练度"）

- 格式：`[主技能] — [X 年] + 具体用途；[次技能] — [X 年]；缺口诚实标注`
- 规则：**评分/下拉字段选诚实的水平，不为最高分优化**——虚高评分会在技术面试中露馅

### Type 5 开放式"介绍你自己"（自我评价）

- 格式：当前角色+做什么（1 句）→ 相关过往经历（1 句）→ 想要什么/为什么这个岗位（1-2 句，公司特定）
- 规则：**从当前角色开始，不从教育开始**；100-200 字；**以向前看收尾**（要什么，不是去过哪）；**无特质声明**（"我充满热情"）——只要事实和项目

### Type 6 情境/行为题（"讲一次你……"）

- 格式：**压缩 STAR（不带标签）**：`[背景 1 句] + [你具体做了什么 2 句] + [带指标的结果 1 句]`
- 规则：具体命名项目/技术/团队规模；不泛化（"我总是这样处理问题"）；150-250 字；第一人称主动；**以结果收尾，不以教训收尾**（教训留到面试）；素材复用 interview-prep 故事库的短版

### Type 7 观点/愿景题（"未来什么技术重要"）

- 格式：真实观点，选一两点简要解释推理
- 规则：**有真正的立场**——含糊答案会被遗忘；观点基于领域知识或真实经验；100-150 字；不全盘对冲——承诺一个观点并承认它只是一种视角

## 4. 长度校准

| 字段类型 | 目标长度 |
|---|---|
| 单行文本 | 1 句 |
| 短答 | 2-4 句 |
| 长答/文本域 | 100-250 字 |
| "描述你的经验" | 150-300 字 |
| "介绍你自己" | 100-200 字 |
| 作品集/链接区 | 列表格式，无散文 |

- 兜底原则：**拿不准时更短更好**——招聘者扫读表单答案，目标是清晰难忘而非面面俱到。

## 5. 常见错误自检（生成后逐项过一遍）

1. **重复 JD**：答案不能是 JD 要求的复述——用具体的公司/岗位细节（如"吸引我的是毫秒级延迟的医疗数据场景"）替换
2. **泛泛特质声明**："我是快速学习者，擅长协作"——直接描述实际工作，特质自然流露
3. **过度限定**："虽然我可能没有正好 5 年……"——正面回应：**"岗位提到 5 年——我有 3 年，但我交付的系统都是生产级的"**（直面差距不道歉，与主动触达 skill 同规则）
4. **无上下文列举**："React, Vue, Angular……"——给主次与年限："React 是主力框架——4 年，跨多个项目；Vue/Angular 各约 3 年，主要用于后台系统"
5. **注水填充**：加不相关项目显得高产——只放与这个岗位相关的

## 6. 输出形态

- 答案**总包在纯代码块**里便于干净复制粘贴；多字段答案每字段一个代码块 + 上方标签（如"期望薪资"、"自我评价"）。

## 7. 边界与联动

- **期望薪资字段**：国内表单常为必填——先问用户期望，按"用户期望 ± 合理范围"给区间填写，不替用户决定；话术策略见 negotiation skill（deflection 与区间报价）
- **行为题答案** = interview-prep 故事库短版（60s）+ 压缩 STAR——素材复用，不重复生成
- 与专属简历/tailoredResume 的内容一致性：同一经历两处表述不得冲突（同一事实源）
- 表单答案全部基于简历原文 + JD 上下文，缺细节标注待用户补充，**不顺手编造**
