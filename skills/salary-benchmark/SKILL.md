# 薪资基准

## 1. 适用场景与边界

- 适用：判断 offer 薪资是否合理、谈薪前的市场基准、多 offer 横向比较（配合 offer-evaluation / negotiation）
- 边界：**区间是参考不是承诺**；数据时效与样本偏差必须标注；不虚构行业数字
- 产出：参考区间（下限-中位-上限）+ 修正因子说明 + 数据来源列表

## 2. 调研流程（web 工具链）

### 2.1 数据检索（webSearch）

- 搜索词组合（按需轮换）：
  - `<岗位> <城市> 薪资` / `<岗位> <城市> 工资`（通用行情）
  - `<岗位> 薪资 2025`（时效修正，按当前年份）
  - `<公司> <岗位> 薪资`（特定公司，配合 offer 评估）
- 优先来源：招聘平台薪资数据（BOSS/猎聘/看准）、薪资统计网站、行业报告、知乎/脉脉讨论（标注主观）

### 2.2 数据抓取（webFetch）

- 对包含薪资区间/统计的页面 webFetch 取正文
- 提取：区间数字、样本量（有则标注）、统计时间、城市/年限口径

## 3. 区间分析

- **基准区间**：从可查数据归纳下限-中位-上限（至少 2 个独立来源才给区间，单一来源标注"单一来源"）
- **修正因子**（逐项说明依据）：
  - 城市：一线 vs 新一线 vs 二三线（通常按 0.7-1.0 系数折算，标注估算）
  - 年限：初级/中级/高级（按招聘 JD 年限要求定位）
  - 公司规模：大厂 vs 中型 vs 创业（大厂通常溢价 10-30%，标注估算）
  - 行业：互联网/金融/制造差异（有数据时引用，无则标注"行业差异未验证"）
- **置信度**：高（多来源一致）/ 中（单一来源或口径模糊）/ 低（检索不到，给出提示而非数字）

## 4. 输出格式

```
# <岗位>薪资参考（<城市>，<检索日期>）
## 参考区间：下限 X - 中位 Y - 上限 Z（<币种/口径：月薪或年包>）
## 修正说明：城市/年限/规模/行业逐项（标注估算依据）
## 数据来源：URL 列表（每条标注类型：招聘平台/统计/讨论）
## 置信度与限制：样本偏差/时效/口径说明
```

## 5. 诚实边界

- 不编造检索不到的区间（输出"未检索到可靠数据" + 建议获取途径：招聘平台同岗薪资/猎头反馈/用户已知信息）
- 不把匿名讨论的个例当统计；单一来源明确标注
- 区间用于参考与谈薪锚定，最终决定权在用户（配合 negotiation 的止损线）
